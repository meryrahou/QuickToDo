# QuickToDo

## Overview

QuickToDo is a Swift-based iOS application developed to provide users with an intuitive and efficient platform for managing their tasks. The application leverages modern iOS development frameworks and design patterns to ensure a seamless user experience.

## Features

- **Task Management**: Create, edit, and delete tasks with ease.
- **User Interface**: Designed with SwiftUI for a responsive and modern look.
- **Data Persistence**: Utilizes CoreData for local data storage.
- **Architecture**: Implemented using the MVVM (Model-View-ViewModel) design pattern.

## Status

**Ongoing**

This project was initiated out of the need for a simple to-do list application that offers minimalism — an icon in the Mac top bar with a popup, free from unnecessary features. I built the initial version in an hour and have since continued enhancing it with new features and improvements. Suggestions are always welcome as I work to refine and expand the app.
